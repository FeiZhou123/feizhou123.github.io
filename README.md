# Fei Zhou — Academic Website

This repository contains the source for Fei Zhou's public academic website. It is a small,
dependency-free static site designed for GitHub Pages.

## 中文维护说明

- 修改个人简介、研究方向或经历：编辑 `index.html`。
- 新增论文：在 `publications.html` 对应年份下复制一个 `article` 区块，并替换标题、作者、会议信息与链接。
- 新增动态：在 `index.html` 的 `news-list` 中增加一条记录。
- 修改颜色、字号或间距：编辑 `styles.css` 顶部的变量。
- 菜单交互：位于 `script.js`，一般不需要修改。

## 免费发布到 GitHub Pages

1. 将仓库命名为 `你的GitHub用户名.github.io`。
2. 在仓库 Settings → Pages 中选择从主分支根目录发布。
3. 发布后访问 `https://你的GitHub用户名.github.io`。

The site intentionally omits a downloadable CV until a public version without a personal phone
number is prepared.
